# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within MCP Sentinel, please report it privately. Do not report security vulnerabilities through public GitHub issues.

Please send an email to the repository maintainer with details, proof-of-concept steps, and affected components. We will acknowledge receipt within 48 hours and work on a remediation release promptly.
